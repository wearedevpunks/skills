# Generic Grilling Gate

## Entry guard

One exact Fog and immutable intake lens exist, and the bounded intake result is
not ready.

## Bounded action

1. Read every direct generic `Kind/grilling` child and its support evidence.
2. Reuse one obviously relevant child. Create another child only when current
   evidence supports separate useful work. When relevance is genuinely
   ambiguous, request human steering before any create intent.
3. For a new child, allocate one durable wiki identity and ask `$write-backlog`
   to ensure its generic shell and exact supported-by relations.
4. Run one atomic `$grilling` conversation using the invoking wrapper's intake
   and presentation profile, including its `$wait-what` and `$show-me`
   behavior. Unknown values remain explicit.
5. When a precise unknown needs readonly facts or a human-evaluated artifact,
   record the named child and route to Research or Prototype.
6. Retain accepted bounded evidence. If optional structure is useful, emit a
   semantic intent within the wrapper's projection ceiling for reconciliation.

## Completion evidence

Exact generic child identity, immutable retained evidence, any support request
and relation, bounded-result state, and optional ceiling-safe projection intent.

## Declared exits

- `support_required` -> router re-entry.
- `projection_requested` -> reconciliation through router re-entry.
- `bounded_result_ready` -> bounded return through router re-entry.
- `human_steering_required` -> handback.
- `blocked` -> stop with missing evidence.

## Durable handoff

Persist child identities, evidence pointers, reuse-or-create decision, support
relations, optional projection intent, bounded-result state, and exit.
